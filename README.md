# 🌍 WhereToGo – Istanbul Travel Recommendation Platform

WhereToGo is a responsive web application designed to help users discover places to visit in Istanbul.  
The platform provides curated travel recommendations, influencer-supported suggestions, and an intuitive discovery experience.

---

## 🚀 Project Overview

WhereToGo was built to simplify the process of exploring Istanbul by offering:

- 📍 Categorized travel recommendations  
- ⭐ Influencer-supported place suggestions  
- 🔎 "Discover" section for easy navigation  
- 📱 Fully responsive design for different screen sizes  

The goal of the project is to combine usability, visual design, and dynamic interaction to enhance user experience.

---

## ✨ Features

- 🗺️ Istanbul travel recommendations (historical, cultural, entertainment, etc.)
- 🎥 Influencer-based highlighted suggestions
- 🔍 Discover section for smooth exploration
- 🎨 Interactive UI design
- 📱 Responsive layout (mobile-friendly)
- ⚡ Dynamic filtering and DOM manipulation

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript (Vanilla JS)**

Key technical implementations:

- DOM manipulation
